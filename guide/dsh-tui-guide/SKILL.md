# dsh-tui user manual (index)

The full manual lives **in this file's directory** — the `resourceBase` the
`skill` tool returned. It ships in English only: every file has the `.en.md`
suffix. Without an absolute path, search the dsh-tui package for
`guide/dsh-tui-guide` with `glob`.

## How to use it

1. **Match the user's language in the answer**, but read the English files — they are the only copy.
2. **Locate before reading**: eleven files by topic; reading a whole file is slow and eats context. `grep` a keyword for the matching lines, then `read` with `offset`/`limit` to expand only the needed passages.
3. **One or two files at a time**: pick the closest row from the routing table; add a second file only for cross-topic questions.
4. **Cite the source**: end the answer with the file name and section title so the user can check it.
5. **Never invent**: say "the manual does not cover this" when it doesn't, then give conservative advice instead of substituting remembered behavior.
